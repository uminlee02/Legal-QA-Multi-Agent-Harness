## 판정 (3A target + 3B control, 3런 mean±std, 내용가짜율 기준)

**Q1 — 스킬이 내용 오적용을 저감하는가? → 모델 순응성에 따라 정반대(2번 패턴 연장).**
- Qwen: 스킬 유해. 맨몸 형사 C0 44.7%→C1 59.9%(+15%p), 민사 16.2→32.5%. 기전 = 스킬이 인용 +23~31%로 요건서술 표면적만 늘리는데 사실검증 실행률 7~16%(회피 지속) → 늘린 서술을 기억으로 날조.
- EXAONE: 개선~중립. RAG 형사 4.1→2.6%. 인용 안 늘리고(C1/C0≈1.0) 사실검증 99~100% 실행.
- 조건 의존: 개선은 RAG(접지) 위에서만. 맨몸은 두 모델 다 무익~악화(대조할 원문 없으면 요건대조=또 다른 기억생성).

**Q2 — 소형 모델이 스킬을 올바르게 라우팅하나? → 비대칭.**
- Qwen 91% vs EXAONE 33%. EXAONE은 '형사'를 한 번도 안 고름(0/282, 전량 민사/기타로 오분류) = 정렬 아티팩트.
- 그러나 EXAONE C2≈C1 — 오라우팅해도 두 스킬 공통 백본(원문인출→요건대조→사실검증)이 도메인 무관 작동. 도메인 특정 게이트보다 백본이 실효의 핵심.
- 충실도 분해: Qwen '단계N' 마커 87~97% 쓰나 사실검증 7~16%만 실행(연기적 순응). EXAONE 마커 11~30%만 쓰나 사실검증 99~100% 실행(실질적 순응). → 스킬 실효 = 절차 낭독 아니라 검증루프 실제 실행.

**Q3 — 스킬 없는 기타 도메인은 불변인가(효과 격리)? → 예, 완전 격리.**
- 대조군(기타+mixed 150) 4개 셀 전부 C0≈C1≈C2. |C1−C0| ≤ 1.4%p (qwen RAG −1.1 / 맨몸 −1.4 / exaone RAG +0.1 / 맨몸 −0.2%p).
- 대조: target C1−C0 (스킬 로드됨) = qwen맨몸 +19.9%p / exaone맨몸 +5.1%p / qwen RAG +2.3 / exaone RAG −0.6%p vs control 전부 ≈0.
- → 스킬 효과(Qwen 악화·EXAONE 개선)는 **스킬이 실제 로드되는 곳에서만** 발생 = C1/C2 하네스 자체는 편향 무주입, 효과는 진짜 스킬 내용 기인. C2가 대조군에서 스킬을 40~42% 오로드해도 C2≈C0 = 잘못 붙은 스킬도 결과 거의 안 바꿈(백본 도메인 중립성 재확인).

**Sanity 통과**: C0 == 2번 자율+게이트(도메인 분해) churn 내 일치. 형식오류 36셀(3A 24+3B 12... 실제 전 셀) 0. SKIP 0. 스킬해시 전 런 동일. temp=0 churn은 3런 std(민사 n=29 소표본 ±4~10%p — 방향만).

**결론(2번 논문 3장 스킬 파트)**: 도메인 검증 스킬은 만능이 아니라 **모델의 실질 순응성에 게이팅됨**. 지시를 실행하는 모델(EXAONE)에겐 접지(RAG) 조건에서 저비용 개선을 주지만, 지시를 낭독만 하고 검증을 회피하는 모델(Qwen)에겐 요건서술 표면적만 키워 오히려 환각을 늘린다. 스킬의 도메인 특정 게이트보다 도메인 불가지론적 검증 백본(원문인출→대조)이 실효의 본체다.
