## 판정 (3런 mean 기준, 느슨=실존가짜율)

**Q1 — 순수 자율(B)은 환각을 늘리는가, 경로는 검증 회피인가? → 예, 확정.**
Qwen-B는 1,356문항 중 1,355건 즉시종료(툴 0, 사실검증 호출률 0%): 맨몸 36.7% vs A 16.4%(2.2배), 내용 66.6% vs 25.7%, gold 1.0% vs 31.9%. RAG는 초기 근거가 가려줘 5.9%≈A 6.0%.
EXAONE-B도 회피(사실검증 5~9%)하되 양상이 다름 — '검색→종료'(67~77%)로 검증 없는 인용을 불려 RAG에서도 A보다 나쁨(7.8% vs 3.8%). 두 모델 모두 B가 어느 조건에선가 A에 뒤짐.

**Q2 — 회피가 Qwen 특정인가 소형 일반인가? → 두 겹: 자발적 검증 회피는 소형 일반, 게이트 순응성은 모델 특정.**
자발적 사실검증 호출률: Qwen-B 0%, EXAONE-B 5~9% — 둘 다 회피(일반). 그러나 게이트 반응이 정반대:
Qwen-C는 규칙 고지에도 사실검증을 안 고르고 논리검증으로 도피(게이트 통과 2~3%, 루프 90~97%, max_steps 97~98%),
EXAONE-C는 100% 순응('사실검증→종료' 최소 순응 76~94%, 루프 ≈1%). → 명제 문구: "소형 온프렘 모델은 자발적으로 검증하지 않는다;
검증을 강제할 수 있느냐는 모델(지시 순응성)에 달렸다." (코드스위칭은 제약 디코딩으로 제어채널에서 제거된 상태의 결과 — 회피는 코드스위칭과 독립)

**Q3 — 종료 전 사실검증 게이트가 회피를 치료하는가? → 모델 의존, EXAONE에선 완치+비용우위, Qwen에선 실패·역효과.**
EXAONE-C: 느슨가짜율이 A보다도 낮음(RAG 2.5% vs 3.8%, 맨몸 9.1% vs 12.7%) + 툴콜 1.1~1.3(A 4.3~5.6의 1/4) + 자율종료 99~100%.
Qwen-C: 툴콜 7.9(A의 1.6배)에 RAG선 B보다 악화(10.5%), 맨몸선 B보단 낫지만(23.7%) A(16.4%)에 못 미침.
단서: ① 게이트가 고치는 건 주로 '실존' 환각 — 내용(엄격)가짜율 맨몸은 세 arm 비슷(A 24.9/B 27.0/C 27.7%), ② EXAONE-C 맨몸 gold 12.1% < A 28.6%(반복 피드백 재생성이 gold 회복에 유리, 1회 검증은 제거 위주), ③ C 게이트 고지 문구 포함(숨은 마스크에선 Qwen·게이트 발견 불가 확인, main_smoke_rag_hiddenmask.*).
