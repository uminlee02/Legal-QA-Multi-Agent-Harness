# 민사법 검증 스킬

## 목적
(1) 민법 조문의 내용 오적용을 잡고, (2) 비민사 조문의 잘못된 인입을 차단한다.

## 검증 절차 (순서대로)

### 0. 도메인 게이트
- 인용 조문이 민법인가? 아니면 플래그·근거 확인·제외.
- 민사 쟁점에 형법을 끌어오면 오적용 신호(교차도메인 차단).

### 1. Issue — 쟁점 확정
- 민사 청구/쟁점을 한 줄로(어떤 권리·의무·책임).

### 2. Rule — 조문 원문 인출
- 적용 민법 조문을 법제처 API로 원문 인출. 실패 시 삭제·교정.
  기억으로 쓰지 않고 인출 원문만.

### 3. Application — 요건사실 대조 (★핵심)
- 인출 조문의 요건을 사실관계와 하나씩 대조:
  · 청구원인: 권리 발생 요건사실이 있는가?
    (예: 불법행위 = 고의·과실 + 위법 + 손해 + 인과관계)
  · 항변: 소멸·저지 사유(변제·시효·상계 등)가 있는가?
- 요건 불충족이면 내용 오적용 → 수정·제거.

### 4. Conclusion — 통과분만 답변, 조문 원문 근거 첨부.

## 실패 시
- 유보("해당 조문만으로 판단 어려움"), 환각 금지.
