# 형사법 검증 스킬

## 목적
(1) 형법·형소법 조문의 내용 오적용(실존 조문을 틀린 맥락에 적용)을 잡고,
(2) 비형사 조문의 잘못된 인입을 차단한다.

## 검증 절차 (순서대로)

### 0. 도메인 게이트 (인용 전 필수)
- 인용하려는 각 조문의 법령명 확인.
- 형법·형소법이 아니면 → 플래그: "이 형사 쟁점에 [법령명]을 적용하는 근거는?"
  정당 근거(특별법 준용 등) 없으면 인용에서 제외.
- 형사 쟁점에 민법·상법을 끌어오면 오적용 신호(교차도메인 차단).

### 1. Issue — 쟁점 확정
- 질문의 형사 쟁점을 한 줄로(어떤 범죄 성립 / 어떤 절차).

### 2. Rule — 조문 원문 인출 (지어내지 말 것)
- 적용할 각 조문을 법제처 API로 원문 인출.
- 인출 실패(=존재하지 않는 조문) → 해당 인용 삭제·"존재하지 않는 조문"으로 교정.
- 기억으로 조문 번호·내용을 쓰지 않는다. 인출된 원문만 근거로.

### 3. Application — 구성요건 대조 (★핵심)
- 인출 조문의 요건을 사실관계와 하나씩 대조:
  · 구성요건 해당성: 규정된 행위·객체·결과가 사실관계에 있는가?
  · 위법성: 조각사유(정당방위·긴급피난 등)가 있는가?
  · 책임: 조각·감경사유(심신장애·연령 등)가 있는가?
- 어느 요건이라도 안 맞으면 → 내용 오적용. 답변에서 수정·제거.
  (예: 형법 제335조(준강도)를 교통사고에 적용 → 절도 기회성 요건 불충족 → 오적용)

### 4. Conclusion — 통과분만 답변
- 0~3 전부 통과한 조문·적용만 포함. 각 결론에 인출 원문을 근거로 첨부.

## 실패 시
- 근거 부족하면 단정 말고 "해당 조문만으로 판단 어려움"으로 유보(환각 금지).
